# Hisaab

Personal and family budgeting web app.

## Stack

- React + Vite + TypeScript
- Tailwind + shadcn/ui
- Supabase (Postgres + Auth + RLS)
- TanStack Query
- Vitest for tests

## Development

```bash
npm install
cp .env.example .env.local   # then fill in Supabase credentials
npm run dev
```
